- `about.md` - вкладка «О себе»
- `projects.json` - вкладка «Репозитории»

Скриншоты 16:9 кладите в `images/`:

- `images/justmoby-unity-kids-2d.png`

## Публикация

1. Создайте на GitHub репозиторий `shawn-edgeworth.github.io`.
2. Залейте эту папку в ветку `main`.
3. Settings - Pages - Deploy from a branch - `main` / root.
